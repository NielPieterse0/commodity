# `.work` layout

`.work/changes/` is versioned operational history for bounded change plans, findings, review records, and closeout evidence.

The following remain local and ignored because they are execution/runtime state rather than repository history:

- `.work/worktrees/`
- `.work/historical/`
- `.work/scratch/` and `.work/quarantine/`
- integration backups, caches, checkpoints, local source/download trees, logs, and temporary files

Product/scientific authority remains in the repository-owned configuration, contracts, research records, tests, artifacts, and maintained documentation described by `AGENTS.md`.
