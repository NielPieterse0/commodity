# 289 Henry Hub literature-reproduction design plan

## Goal
Convert the fresh-programme literature findings into complete unfrozen scientific designs that can reproduce or disconfirm each finding without using legacy scientific outcomes, opening protected evidence, or freezing confirmation authority.

## Design rules
- One primary estimand per design; secondary estimands cannot rescue a failed primary result.
- Translate each literature claim into mechanism, H0/H1, expected/disconfirming observations, source fidelity, exact time/contract semantics, inference, robustness, and a pre-execution MEPI/power gate.
- Preserve strict reproduction, mechanism replication, contextual evidence, and exploratory gap discovery as different evidence classes.
- Use the maximum admissible source-valid sample; never inherit a legacy experiment window merely because it already exists.
- Do not execute literature outcomes in this change.

## Tasks
1. Map every L3 literature finding to a direct reproduction design or an explicit non-reproduction classification.
2. Define global scientific, PIT, contract, multiplicity, MEPI/power, success/failure/inconclusive rules.
3. Define source/readiness dependencies for every design and fail closed on missing consensus, vintages, carry components, or cross-market sources.
4. Reconcile programme metadata to the new experiment design and setup authorities.
5. Verify JSON/source/finding/design-reference integrity and perform independent scientific design review before publication.
